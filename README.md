# bookshelf3

A personal book-tracking app, ported from [MyBookshelf-v3](https://github.com/SKemp25/MyBookshelf-v3).

The library shows **English-language original editions only**. Movie tie-ins, anniversary reissues, graded readers, abridged texts, and summarized study-guide versions are filtered out when books are fetched and when they are displayed.

```bash
npm install
npm run dev
```
